名片小幫手 隱私權政策

生效日期：2026 年 10 月 24 日

名片小幫手（以下稱「本工具」，網址 https://jackyt345.github.io/namecard/）由唐晨峰以個人身分開發並免費提供。本政策說明本工具在你使用時會存取哪些資料、如何使用，以及你可以如何控制這些資料。

一、本工具的運作方式

本工具是一個純前端網頁，所有處理都在你手機或電腦的瀏覽器裡執行。開發者沒有架設任何伺服器或資料庫，也無法看到、收集或保存你的照片、名片內容、Google 帳號資料或 AI 金鑰。

二、透過 Google 帳號存取的資料

你按下「用 Google 帳號開始」並同意授權後，本工具會在你的瀏覽器中取得以下權限，並只用於下列目的：

  • 基本帳號資訊（openid、email）：顯示你目前登入的帳號，並在下次登入時預先選好同一個帳號。
  • Google 雲端硬碟中由本工具建立的檔案（drive.file）：在你的雲端硬碟建立「名片庫」資料夾與「名片總表」試算表，上傳名片照片、寫入辨識結果，以及讀取這些資料供你查詢。這項權限無法讀取你雲端硬碟中其他非本工具建立的檔案。
  • Google 日曆唯讀（calendar.readonly，選用）：只有你在「設定」中主動開啟日曆比對時才會要求。本工具會讀取拍照時間前後 90 分鐘內你主要日曆上的行程名稱與地點，用來填入「活動名稱」欄位，不會建立、修改或刪除任何日曆內容。

Google 授權的存取權杖存放在你的瀏覽器中，約一小時後失效。

三、Google API 使用者資料的有限使用聲明

本工具使用與移轉自 Google API 取得之資訊至任何其他應用程式時，將遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。具體而言：

  • 取得的 Google 使用者資料只用於提供上述名片辨識、歸檔與查詢功能。
  • 不會將這些資料轉移或出售給任何第三人，也不會用於廣告。
  • 開發者本人不會閱讀這些資料；本工具的架構也使開發者無從取得這些資料。
  • 不會使用這些資料開發、改善或訓練任何通用型人工智慧或機器學習模型。

四、名片照片的 AI 辨識

你上傳的名片照片會在瀏覽器中縮小後，直接從你的瀏覽器傳送到 Google 的 Gemini API 進行文字辨識，使用的是你自行申請並填入的 Gemini API 金鑰。這段傳輸由你與 Google 之間的服務關係規範，適用 Gemini API 附加服務條款 與 Google 隱私權政策。依 Google 公告的條款，使用免付費方案時，Google 可能將送出的內容用於改善其產品；如有疑慮，請改用付費方案的金鑰，或避免上傳含有高度敏感資訊的照片。

五、存在你瀏覽器中的資料

為了讓你不必每次重新設定，本工具會在瀏覽器的本機儲存空間（localStorage）保存：Google 存取權杖、登入帳號的 Email、「名片庫」資料夾與「名片總表」的檔案 ID、你的 Gemini API 金鑰，以及是否開啟日曆比對的設定。這些資料只存在你自己的裝置上，不會傳給開發者。本工具不使用 Cookie，也沒有放置任何流量分析或廣告追蹤程式。

六、網站代管

本工具的網頁檔案由 GitHub Pages 代管。你開啟網頁時，GitHub 可能依其政策記錄連線 IP 位址等技術紀錄，相關處理適用 GitHub 隱私權聲明。網頁也會從 Google 載入登入元件。

七、名片上的他人個人資料

名片記載的是名片持有人的姓名、職稱、聯絡方式等個人資料。這些資料只會存進你自己的 Google 雲端硬碟，由你自行保管與利用。請依《個人資料保護法》等相關法令，在合理且與交換名片目的相符的範圍內使用，並妥善設定雲端檔案的分享權限。

八、保存期間與刪除

  • 照片與試算表存放在你的 Google 雲端硬碟，保存多久由你決定，你可以隨時在雲端硬碟中刪除。
  • 你可以到 Google 帳戶的「第三方應用程式和服務」 移除本工具的存取權，移除後本工具將無法再存取你的任何資料。
  • 在「設定」按「移除金鑰」可刪除瀏覽器中的 AI 金鑰；清除瀏覽器的網站資料可刪除本工具存在裝置上的所有設定。

九、兒童

本工具並非針對未滿 13 歲的兒童設計，也不會在知情的情況下處理兒童的資料。

十、政策變更

本政策如有修改，會更新本頁內容與上方的生效日期。重大變更會在本工具首頁提示。
